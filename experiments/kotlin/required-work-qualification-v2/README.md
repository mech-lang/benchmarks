# Retained Kotlin required-work qualification

The [qualification receipt](qualified-work.json) grants required-work qualification to twenty retained source forms, through the [individual decisions](decisions.json). The ten compact/optimized pairs are source aliases, with separate retained classes and native observations. They are not evidence of ten optimizations.

The receipt combines the closed 21-command [compiled-work run](../compiled-work-v1/run-v2/terminal.json), its 186 prior bounded form cases, and four single-entry observations. The first two single-entry producers retain their original failed status. The first failure was a separately preserved VM diagnostic before otherwise exact tree stdout; the second was an overstrict requirement that pi main be JIT compiled. The successful final producer executed only the previously unstarted optimized pi. No earlier subject was rerun or silently normalized.

The review replayed all twenty owned process receipts and start records, constructor/container witnesses, saved subject JIT method records and loaded-class origins. Each retained form completed 10,000 checked main invocations and returns. Current small source, generated-class and disassembly bytes matched their pins. First/last output matched the saved reference. The native-library observations bind the saved original-JDK image pins; operating-system libraries retain the documented vendor-image boundary. No runtime closure was newly hashed during this review.

The four single-entry captures were replayed against complete saved output, runtime/class origins, compiler logs, native process ownership and artifact snapshots. The [first tree review](../single-entry-remaining-v1/first-capture-reconciliation.md), [optimized tree and compact pi review](../single-entry-remaining-v1/actual-instruction-review.md), and [optimized pi review](../single-entry-final-v1/actual-instruction-review.md) retain exact instructions, bytecode offsets and artifact hashes. The optimized pi has seven installed division-method records; compact pi has eight. Neither proves a numeric runtime division-call count.

Qualification concerns required work in these retained implementations and the observed execution paths. It does not assert that every subject method was compiled, that every workload's complete machine instructions were audited, or that the full inputs fit an 8 GiB heap. Full-size k-mer memory feasibility is still unknown. Full timings and chart admission remain false. Canonical source counts are independently qualified; formatted counts remain false/null.

The additive [full90 adapter](../full90-v2/README.md) requires this exact native/review chain and every form's decision. Before native measurement, its normal locked preparation verifies the complete retained pin and artifact closure again.
