# Split-stage Rebol qualification intake

This additive consumer replays the actual remaining-fixture, bounded and work
observation records through the original qualification checks. Each producer
keeps its original controller identity and records its actual adapter entrypoint
and command. Original failed attempts and all earlier source files remain intact.

The corrected regex count admission supplies an isolated copy of the original
fifteen-source owner ledger. The existing counter still replays every owner,
source digest and complete bundle. The exact regex replacement must agree in
the count proposal, independent admission and binding helper; no ledger or prior
count record is rewritten.

This module launches no native processes. It requires actual independent
primitive, bounded-work and source-count dispositions before yielding a timing
input context. The original held-lease verification, output checks, runtime
limitations and failure cleanup remain in force. A passing source test does not
qualify a native workload or admit timing data.
