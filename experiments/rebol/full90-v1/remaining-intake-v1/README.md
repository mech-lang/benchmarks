# Full90 intake after split qualification

This additive entrypoint connects the reviewed remaining-evidence qualification adapter to the frozen full90 producer. It preserves the original producer file identity, packet, suite lease, ninety-slot rotation, sampler, independent receipt checks, reports and finalization. The qualification consumer still requires actual bounded correctness, required-work and exact source-count evidence before preparation; no qualification manifest is manufactured here.

The source review uses schema `rebol-full90-remaining-source-review-v1` and status `independent-source-review-complete-native-timing-pending`. Its six `files` are the original producer/test/README and this adapter/test/README. Its seven `dependencies` are the original qualification consumer, frozen timing helpers and receipt reader, and the exact qualification/work/bounded/primitive intake adapters. All source bytes and helper pins are verified before the adapted qualification context is returned. Original qualification and producer roots remain unchanged.

The plan adds explicit `intake_adapter`, `qualification_intake_adapter`, `work_intake_adapter`, `bounded_intake_adapter`, `primitive_intake_adapter` and `entrypoint` identities. Output must be fresh and physically contained in this nested packet. The original plan schema and timing policy remain unchanged: sixty fresh subject samples and thirty matched Mech controls, with three rotated rounds for ten workloads. Equivalent source forms receive independent process samples; no timing alias is copied. Runtime startup, source/helper evaluation, extension loading, input, work, output and shutdown remain inside each process timer. Existing limits and all failure, cleanup and admission gates are unchanged.

The CLI is `tools/qualification/rebol_full_remaining.py --adapter-sha256 SHA --qualification-adapter-sha256 SHA --work-adapter-sha256 SHA --bounded-adapter-sha256 SHA --primitive-adapter-sha256 SHA prepare|run`, followed by the original producer's options. `load_controller(expected, qualification_expected, work_expected, bounded_expected, primitive_expected)` returns the original producer with only source intake and plan metadata routing adapted.

Focused pure checks cover immutable execution functions and ninety-slot rotation, exact source/dependency review, the actual adapter loader identity, rejected chain substitutions, output confinement, metadata-only plan changes and CLI dispatch. Their execution is recorded separately. No full90 preparation or native timing result is asserted by this packet.
