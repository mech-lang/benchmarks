# Combined prerequisite intake for Rebol bounded cases

`rebol_bounded_combined.py` extends the frozen shared149 controller's evidence
intake. It requires the actual primitive19 approval, the exact primitive adapter
entrypoint and all three extension jobs. The failed extension loads remain in
their original records. The diagnostic helper's supplemental Apple header is
recorded separately from the selected SDK.

The original bounded schedule, ten selected programs, output checker, observer,
limits and finalizer remain unchanged. The 149 cases comprise 142 successful
outputs and seven expected invalid-IUPAC rejections. No interposer is loaded by
the benchmark programs. This stage produces correctness evidence, not timings;
independent review is required before any qualification gate changes.
