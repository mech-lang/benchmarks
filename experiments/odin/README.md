# Odin implementation audit

[source-review-v1](source-review-v1/README.md) records a complete source inspection
of the thirteen local/derived Odin implementations across nine workloads,
retained historical timings in seconds and multiples of Mech AOT, exact source
identities, original-lineage gaps and raw source-size measures. The two unchanged
upstream N-body submissions remain protected.

[spectral-scratch-v1](spectral-scratch-v1/README.md) is the first new candidate:
ordinary reusable scratch storage with the known original source and license
retained. It is uncompiled and unmeasured. Native qualification, generated-code
inspection, normalized/formatted source counts and isolated timing comparisons
remain pending. No catalog source, timing or chart selection changes here.
