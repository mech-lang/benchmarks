# Selected-record pilot: prepared, not executed

This separate controller prepares one shuffled fresh-process observation for
the exact retained parent, serial rolling source and seven-width task source.
There is no full-size mode. All three observations must be retained, with no
automatic retry or source-count/chart admission.

The diagnostic input contains the first 1,000,000 selected DNA bases from THREE
in the exact shared full input. It retains the original header/base bytes and
reconstructs 60-column lines. Earlier records are omitted, so this pilot does
not measure the complete full-input parsing boundary. The shared source file,
derivation helper, output payload and independent direct-window Python Counter
reference are hash-bound. Generation/compression/hashing occur before all
measured subjects and outside their process timers. The saved compressed input
permits later exact replay without retaining the full 254 MB source input.

Each measured process includes runtime startup, loading its own exact BEAM,
stdin reads, parsing/encoding, all 6,999,961 required map updates across seven
complete histograms, task setup/results where applicable, output and exit.
Power, competing-process, file-integrity and common-mutex checks bracket the
processes. Complete stdout must match both the independent reference and the
retained parent. The environment/OTP/Elixir/flags match native qualification.

Prepare/check-only is metadata work. Execution remains a separate authorized
quiet-window action; no pilot was run to create this plan. Full-size candidate
selection and a separate full schedule must follow the pilot rather than being
inferred here. Source counts and source formatting remain unassigned.
