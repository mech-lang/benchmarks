# Elixir full-suite publication

The retained Elixir 1.20.4 / Erlang OTP 29 cohort contains sixty Elixir measurements
and thirty matched Mech AOT controls across ten workloads. Every form and control
has three qualified samples. The serialized run completed on October 14, 2026;
independent reconciliation found no failed profiles, repeated samples, skipped
slots, process-identity gaps or artifact-integrity failures.

All twenty source-form records remain available in the program inventory. Each
workload's two retained form identifiers use identical authored sources; their
independent measurements do not establish a distinct compiler optimization.
Ten selected endpoints enter the chart. Canonical and formatted LOC include the
application, its authored helper and its launcher. Existing timing and source-size
baselines remain unchanged.

[The import receipt](import-receipt.json) binds the exact candidate, reconciliation,
tool source and resulting publication files. [Validation](validation.json) records
the repository, language metadata, chart-layer and source-inspector checks, plus
all 33 built asset hashes verified against their build manifest. The underlying
[measurement report](../full90-v1/run-v1/report.json),
[reconciliation](../full90-v1/reconciliation-v1.json) and
[publication candidate](../full90-v1/publication-candidate-v1.json) retain sample
and runtime provenance. Original producer admission flags remain unchanged;
publication is recorded separately.

Runtime details were observed in separate closed qualification processes and
bound to the unchanged timed executable and source closure. Numeric GC defaults
and regex JIT are not claimed. Full stdout is represented by the sampler's byte
counts, hashes and validation receipts; the complete output streams were not
retained. Peak process-group memory is sampled rather than continuously observed.
