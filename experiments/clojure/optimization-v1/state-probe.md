# Untimed n-body state probe

`state_probe.clj` is a separate qualification script, not benchmark source or an admitted timing sample. It requires the original compact namespace and both isolated candidate namespaces. Run it only in the root-owned serial qualification window, using the pinned JDK/Clojure jars and the previously built application/support class directories. Omit original/candidate source directories from the classpath so `require` resolves the intended compiled classes rather than selecting a newer source file. The controller should pin the script, class files, jars and complete command.

For each independent n=0,1,2,3,10,100 case, the script creates fresh systems from all three implementations. It compares all35 state slots by `Double.doubleToRawLongBits`, including masses and signed zero, before momentum offset, after offset, and after every individual `advance` call. It also compares energy by raw double bits at every one of those checkpoints. A state or energy difference throws with case/step/phase and candidate identity. Successful output is one EDN record describing the checks, including348 actual calls to the three `advance` functions combined. This does not compare only rounded final energy or a floating tolerance.

The script never redefines the implementations or substitutes another transition. It adds no native helper and uses only ordinary Clojure primitive arrays and the standard JDK raw-bit operation. Probe allocation and repeated energy calculations are untimed validation work. They must not be inserted into performance processes.

There is no dynamic counter for inner pairs, individual velocity stores or position stores. Those counts remain **source-only proof** here: unchanged i/j loops visit ten unordered pairs per step; the candidate spells six ordered velocity stores per pair and three position stores for each of five bodies. The script witnesses the requested number of actual `advance` invocations and their entire externally visible state, but does not claim to instrument600million stores or establish backend machine instructions. A separate instrumented source twin would need its own source delta and explicit exclusion from timing before stronger runtime count claims.

This file and script were prepared without a Clojure/JDK/compiler/test invocation. Root owns execution and subsequent acceptance of the complete evidence.
