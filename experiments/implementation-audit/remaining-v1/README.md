# Database-wide implementation improvement queue

[queue.json](queue.json) binds all retained profiles to the current catalog,
ownership inventory and language-family metadata. It covers every family,
including protected-only families and shared-source execution modes. It is an
execution queue, not a claim that previously unreviewed sources have now been
reviewed, optimized, counted or measured. Regeneration starts no native process.

New candidates retain the original source and citations. Every authored workload
helper remains application source; generic binding exclusions require the same
documented source boundary as the retained comparison. Source identity can share
an inspection across modes but cannot merge their observations or establish a
runtime result. Upstream submissions stay unchanged. Unresolved ownership is a
lineage review task before any source rewriting.

Candidate progression is explicit: source inspection, ordinary-language/library
alternative, native compilation, bounded independent output and work checks,
source-count qualification, isolated pilot, preselected fresh full-process
comparison, guarded admission. A candidate can fail any gate; all attempts stay
available. Size and speed are independent outcomes. Whole-process samples include
startup, JIT where applicable, input, work, complete output and shutdown.

The current next tranche examines TypeScript nucleotide substring allocation,
Crystal regex position handling, Pony tree scheduling, R fannkuch gather
allocations and D reverse-complement buffering. These are source hypotheses;
none has a new admitted timing in this queue. Existing Nim, Elixir and Lean
candidate packets remain separate qualification work. Quantitative benchmarks
share one exclusive timing lock and never run concurrently.

Timing reports include elapsed seconds and `elapsed / Mech AOT elapsed` for the
same benchmark and input size. The denominator is the fastest eligible measured
Mech AOT implementation in the cited catalog snapshot, identified by profile,
samples and original measurement report. A value above 1 means more elapsed time
than Mech AOT. Historical-baseline ratios are distinguished from fresh matched
control comparisons; neither measurement is silently replaced or pooled.

Reduced-input pilots retain their raw seconds. Their Mech AOT multiple is
unavailable unless an equivalent reduced-input Mech AOT measurement exists; a
full-size baseline cannot supply that denominator. The chart continues to use
its independent best-time normalization.
