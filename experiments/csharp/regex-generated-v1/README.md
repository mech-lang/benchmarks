# C# source-generated regex alternative

This uncompiled form declares all fifteen regular expressions through the
standard SDK `GeneratedRegex` feature. Nine count jobs and one job containing
the five ordered substitutions share a maximum-eight-body `Parallel.For`.
Ordered printing follows completion. Byte-preserving input decoding and every
pattern, complete count, replacement and reported length remain application
logic.

The original lineage is the local
[PCRE2 C# #2](https://benchmarksgame-team.pages.debian.net/benchmarksgame/program/regexredux-csharpcore-2.html)
adaptation by Michael Ganss, derived from Josh Goldfoot with Anthony Lloyd's
ordering changes. Original notices and [BSD terms](LICENSE.benchmarksgame) remain,
with Apache-2.0 for local edits. Current edits identify Codex GPT-6 with the exact
serving model unknown; predecessor attribution is not inferred.

This is ordinary framework regex compilation, with no new C/native benchmark
executor. All authored attributes, partial method declarations and orchestration
count as application source. Emitted C# must be captured and bound to the exact
SDK as compiler output; no source-count boundary is approved merely by preparing
this draft. Source-generator diagnostics/fallbacks, complete outputs, required
work, native ownership/formatting and JIT/NativeAOT observations remain pending.
The project enables capture of compiler-generated files; neither compilation nor
that capture has run.
