# Apple M3 handoff

Start with the published Cranelift encoder and target 81/81 fixture wins and 12/12 Silesia wins against each pinned reference in both timing orders. The published Apple M1 run meets that target. Save the M3 measurements in a new run directory. [81-case scores](scores.json) · [Silesia scores](silesia-scores.json) · [Winning recipe](recipe.json).

Use arm64 macOS 15 or later, Apple Command Line Tools, Python 3.12 or later, and Rustup. Run the commands from a directory where you can create two checkouts.

```sh
git clone --filter=blob:none --single-branch --branch codex/m3-deflate-81 \
  https://github.com/mech-lang/mech.git mech-m3
git -C mech-m3 checkout --detach 35784003b9149fe8059fa83dd5d0aff10dbcd631
git clone --filter=blob:none --sparse --single-branch --branch codex/m3-deflate-81 \
  https://github.com/mech-lang/benchmarks.git benchmarks-m3
git -C benchmarks-m3 sparse-checkout set \
  experiments/mech/mechdeflate-cranelift-v1 \
  experiments/mech/mechdeflate-81-v1 \
  experiments/mech/mechdeflate-phase-routes-v1 \
  experiments/mech/mechdeflate-masked-fields-v1 \
  experiments/mech/mechdeflate-silesia-v1

mech_checkout="$PWD/mech-m3"
bench_checkout="$PWD/benchmarks-m3"
packet="$bench_checkout/experiments/mech/mechdeflate-cranelift-v1"
corpus_packet="$bench_checkout/experiments/mech/mechdeflate-silesia-v1"
recipe="$packet/word-mismatch-order/recipe.json"
m3_run=$(mktemp -d "${TMPDIR:-/tmp}/mechdeflate-m3.XXXXXX")

rustup toolchain install nightly-2026-03-03 --profile minimal
{
  sysctl -n machdep.cpu.brand_string
  uname -m
  sw_vers
  rustc +nightly-2026-03-03 -vV
  git -C "$mech_checkout" rev-parse HEAD
  git -C "$bench_checkout" rev-parse HEAD
} > "$m3_run/host.txt"

python3 -B "$corpus_packet/fetch_silesia.py" --manifest \
  "$corpus_packet/corpus.json" "$m3_run/silesia-inputs"
python3 -B "$packet/verify.py" --record "$packet/word-mismatch-order" \
  --output "$m3_run/verified-m1"
```

## Run the shipped encoders

The replay verifies the pinned actors and input inventory. It records both timing orders and checks compressed bytes and independent inflation.

```sh
python3 -B "$packet/replay.py" --recipe "$recipe" --suite all \
  --corpus "$m3_run/silesia-inputs" --output "$m3_run/shipped"
```

## Rebuild and measure on M3

The rebuild verifies the native object, canonical bytecode and descriptor against the recipe. Pass the shipped control worker alongside the locally built candidate.

```sh
python3 -B "$packet/rebuild.py" --recipe "$recipe" --mech-root "$mech_checkout" \
  --output "$m3_run/build" --target-dir "$m3_run/cargo-target"
python3 -B "$packet/replay.py" --recipe "$recipe" --suite all \
  --build "$m3_run/build" --control-build "$packet/actors" \
  --corpus "$m3_run/silesia-inputs" --output "$m3_run/rebuilt"
```

Run the timing commands serially on the M3. Keep `host.txt`, the build receipt under `build/word-mismatch-order/receipt.json`, and the `suite81` and `silesia` directories from each replay. Start with `suite81/cranelift-results.json` and `silesia/scores.json` to find cases that miss the target. Each suite keeps the raw timings for both orders.

Keep the pinned inputs and references fixed when testing local Mech changes. Use `--suite 81` or `--suite silesia` for iteration, then use `--suite all` to confirm both suites on a single build.
