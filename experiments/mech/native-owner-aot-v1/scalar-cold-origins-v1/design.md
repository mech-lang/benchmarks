# Cold source-origin materialization for closed scalar bodies

The qualified parent performs unconditional stores to the Frame error-node word before source operations in the compiled scanner. Successful body operations within a proved closed scalar region cannot observe that private error word. Loop headers retain their eager writes because normal input-checkpoint validation reads the header origin. The owning helper receives the source site explicitly; ordinary callbacks retain their original eager origin store.

This independent candidate creates a cold exceptional trampoline for each proved closed non-map body site, excluding its header. The trampoline stores the exact original site before reaching the unchanged common abort/cleanup block. All source checks and statuses remain; source actions, original body prices, metadata homes and the finite two-dimensional loan protocol are unchanged. Additional exceptional-template instructions are included in the existing per-site code-bound validation.

The optimization selects only existing closed scalar proofs, without recognizing any benchmark, marker or input content. Non-scalar, map and non-program paths retain their old eager stores. Prefix pause/resume source checks and explicit callback site arguments remain unchanged.

Differential tests compile original and decoded bytecode with and without this change. They compare repeated prefix/resume traces, cleared checkpoints, original work, errors and origins under finite compute/comparison caps and varied inputs. A separate general scalar state machine checks arithmetic overflow at its actual source site. The complete native capture, resource, map and error suite and catalog check remain gates.

IR84 identifies the new emitter; ABI29 and policy68 remain. The qualified worker-credit parent is retained. The unpromoted IR83 register experiment and IR82 join/map fusion are not included. Primary timings contain secured complete-process runs under the unchanged benchmark work contract; profiled diagnostic executions are reported separately.
