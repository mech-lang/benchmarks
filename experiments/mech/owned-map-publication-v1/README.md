# Canonical publication from retained map storage

Compiler revision `5047ac667f7a739fa9499dbf30b0c855a507e642` adds an internal output boundary for retained String/U64 hash-table storage. It copies a completed table into an independently owned canonical Mech map, using the existing invocation memory/work accounts. It implements no input traversal, window construction, increment or benchmark algorithm. The retained table remains unchanged, including on denial or publication failure.

Publication requires finite output-element, output-byte, temporary-byte, cloned-byte, retained-node, compute and comparison limits. Caller geometry must include the retained owner and any coexisting prior output. A future native caller must still derive that complete geometry from actual frame/owner state and prove the exact selected site and lifetime; descriptive geometry alone grants no execution or publication authority.

The storage bridge validates String/U64 output schemas and exact, dynamic or constant-bounded cardinality. It prepays traversal of the complete shared schema arena, reserves a conservative coexistence envelope before allocating reference order, key copies or canonical drafts, and imports the result into the same account. Borrowed entries are ordered by a fallible, allocation-free heapsort. Each comparison is charged before key bytes are examined; denial releases only workspace and preserves already spent work. Sorted drafts use the common canonical finalizer's append route rather than rebuilding an unordered map through quadratic insertions.

Three pre-existing checks remain ignored. `publication-v1` retains the first sixteen-check storage/publication run; `native-regressions-v1` includes the final typed native transport check and the broad suite.

Checks cover empty maps, arbitrary values including `u64::MAX`, Unicode and embedded NUL keys, independent immutable prior outputs, same/foreign memory accounts, global memory denial and retry, omitted caller geometry, exact/one-short temporary and output bounds, all seven finite call dimensions, sorting denial with retained work on retry, schema/cardinality rejection, long shared prefixes and release of all retained claims. The native transport check admits published results into a same-account typed arena, rejects wrong types and foreign work ledgers, invalidates replaced handles, and preserves an independently retained older snapshot.
