## Reproduction and safety

frozen study seals, raw timings, complete outputs, required work, source counts
and source/build identity. It produces a reviewable preview with both input and
output catalog digests. `apply --expected-preview-sha256 DIGEST` reproduces that
preview before installing the benchmark and language catalogs. A changed input,
changed evidence, changed preview, duplicate identity or new global minimum is
rejected. Partial writes roll back without overwriting unexpected external edits.
`SUCCESS.json` records the completed apply. No new normalization baseline is set.

without relaxing its older checks. The authorship auditor binds only the three

from the updated catalog; existing source outcomes remain unchanged.

binding, selected endpoints, source and proof drift, scoped authoring metadata,

receipts are retained in `validation/`. The website deployment receipt is separate
