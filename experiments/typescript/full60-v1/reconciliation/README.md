# Independent TypeScript full60 reconciliation

The [independent verifier](../../../../tools/qualification/typescript_reconcile.py)
checks a completed first full-size TypeScript cohort: ten authored
implementations and ten matched Mech controls, with three fresh observations
per profile. It imports only the frozen independent receipt validators. It does
not import or execute the measurement producer, sampler, Node, compiler or
benchmark. This source packet contains no prepared plan or timing results.

The pure ledger independently reconstructs all sixty alternating slots. Every
actual attempt must match its raw sampler, supervised sampler and outer ownership
receipts, the exact direct Node command, its full input and output reference,
source/runtime fingerprint, serial interval and validated receipt snapshots.
The durable command is exactly the retained Python with `-I -S -B -u`, absolute
controller/plan paths and the reviewed plan digest. Controller birth, parent,
argv and exit evidence must agree. Isolated workload failures retain their real
receipts and earlier samples, without partial medians. A failed matched control
leaves the subject's matched ratio unset. Missing output fields on a timeout
are not invented.

The file stage independently joins the ten authored TypeScript files, unchanged
compiler inputs, emitted JavaScript, maps, native ASTs, canonical projections
and 27 required-work contracts. It binds the actual 149-case correctness review,
lossless tree/pi output partitions, native instruction reviews and all inherited
pins. The original three-command diagnostic producer remains failed on its
recorded output-parser assumption; its complete tree capture is reused through
the separate reviewed evidence. Pi's missing-only capture remains a single
invocation. Neither is counted as a timing sample.

Five exact prerequisite inventories cover strict compilation and AST capture,
bounded correctness, the original capability/tree capture, the pi-only capture,
and forty source projections plus their replay. Canonical authored source counts
are admitted; formatted counts remain null. The emitted JavaScript and maps are
retained execution inputs, not substitutes for the authored TypeScript count.

The exact Node binary, recorded embedded versions, application module closure,
static Mach-O declared system libraries and OS build come from the existing
runtime admission. File review preserves that declared-dependency scope.
`actual_loaded_image_inventory_observed` and `observed_in_each_timed_process`
remain false; no new native probe or loaded-image claim is introduced.

Three existing leases remain held through file verification and any consuming
publication operation: the completed durable job lease, TypeScript cohort lease
and original common timing mutex. The job has exactly its nine registered files;
the timing directory has only its report, terminal and three receipts per actual
attempt. Every verified digest, prerequisite inventory, result inventory and
named lease identity is checked again before release. The result's creation
inode and exact written bytes are also checked after final input verification.
A failure removes only output still owned by this invocation; external changes
are preserved and reported. Optional consumer validation and guarded restoration
run while all leases remain held.

The result schema is `typescript-independent-full60-reconciliation-v1`.
Successful file review reports `full60-reconciled-awaiting-publication-review`,
`file_integrity_verified: true`, the reused runtime admission and its explicit
scope, authenticated plan/report/terminal references, `verified_file_pins`,
and a twenty-profile map with samples, medians, sample standard deviations,
failed-attempt identities and matched-control ratios. `chart_admission` and
`full_timings_qualified` remain false. Publication selection and catalog
preservation are separate requirements.

The frozen sampler validates complete successful stdout and discards it. Timing
evidence therefore consists of its byte count, digest and validation receipt;
this verifier does not claim to replay discarded stdout. Process-group RSS is
sampled, not a continuously observed maximum. Kernel identity observation gaps
remain explicit.
