What these metrics measure

Source counts read immutable Git objects. Working edits and untracked files are excluded. Physical lines include comments and blank lines. The inventory excludes vendor, build-output and dependency directories; checked-in source remains counted. These are repository size measurements, not a language-neutral complexity score.

Rust test files are identified by test directory and filename conventions. Inline tests remain in their owning source files, and generated test cases are not enumerated. A test-file inventory is distinct from executed tests and line coverage. Coverage stays unavailable until a real coverage report is retained.

Dependency declarations include optional, development, build and target-specific entries. Locked packages describe the recorded root Cargo.lock, not the dependencies enabled for one build. CI rows identify GitHub workflows associated with the selected revision; their jobs can include build and validation steps. Source tracks keep different branches and measurement policies separate.
